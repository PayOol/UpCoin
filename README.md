# UpCoin

UpCoin est une boutique web permettant de choisir un pack de pièces TikTok et
de lancer une commande avec paiement Mobile Money.

## Développement local

Prérequis : Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Pour générer la version de production :

```bash
npm run build
```
